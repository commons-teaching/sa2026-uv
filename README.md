## Batch folders

The main working files for this batch are under [`docs/mapp_project_000050/mapp_batch_000284/`](docs/mapp_project_000050/mapp_batch_000284/).

- [`metadata/`](docs/mapp_project_000050/mapp_batch_000284/metadata/): raw and curated sample metadata.
- [`metadata/original/`](docs/mapp_project_000050/mapp_batch_000284/metadata/original/): original metadata files as received.
- [`metadata/treated/`](docs/mapp_project_000050/mapp_batch_000284/metadata/treated/): cleaned or transformed metadata files.
- [`results/`](docs/mapp_project_000050/mapp_batch_000284/results/): analysis outputs generated for the batch.
- [`results/cytoscape/`](docs/mapp_project_000050/mapp_batch_000284/results/cytoscape/): network files and exports for Cytoscape.
- [`results/met_annot_enhancer/`](docs/mapp_project_000050/mapp_batch_000284/results/met_annot_enhancer/): metabolite annotation enhancement outputs.
- [`results/metaboanalyst/`](docs/mapp_project_000050/mapp_batch_000284/results/metaboanalyst/): MetaboAnalyst-ready files and outputs.
- [`results/mzmine/`](docs/mapp_project_000050/mapp_batch_000284/results/mzmine/): MZmine batch files and processing outputs.
- [`results/sirius/`](docs/mapp_project_000050/mapp_batch_000284/results/sirius/): SIRIUS/CSI:FingerID outputs.
- [`results/stats/`](docs/mapp_project_000050/mapp_batch_000284/results/stats/): statistical analysis outputs.
- [`results/xcalibur/`](docs/mapp_project_000050/mapp_batch_000284/results/xcalibur/): Xcalibur exports and related files.
- [`report/`](docs/mapp_project_000050/mapp_batch_000284/report/): rendered or intermediate report files.
